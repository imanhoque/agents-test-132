# AI-Powered Stock Analyzer 📈

An interactive stock analysis tool powered by GPT-5 and real-time market data.

## Features

- 📊 **Real-time Stock Data**: Fetches live stock information using Yahoo Finance
- 🤖 **AI Analysis**: Leverages GPT-5 to provide intelligent stock insights
- 📈 **Interactive Charts**: Beautiful candlestick charts with customizable time periods
- 💹 **Key Metrics**: Displays price, market cap, P/E ratio, volume, and more
- 🎨 **Modern UI**: Clean, responsive Streamlit interface

## Installation

1. Clone this repository:
```bash
git clone https://github.com/YOUR_USERNAME/agents-test.git
cd agents-test
```

2. Install required packages:
```bash
pip install -r requirements.txt
```

3. Set up your OpenAI API key:
```bash
export OPENAI_API_KEY='your-api-key-here'
```

## Usage

### Streamlit Web App
```bash
streamlit run streamlit_app.py
```

### Command Line Script
```bash
python main.py
```

## Requirements

- Python 3.8+
- OpenAI API key
- Internet connection for real-time data

## Technologies Used

- **OpenAI GPT-5**: AI-powered stock analysis
- **yfinance**: Real-time stock data
- **Streamlit**: Web interface
- **Plotly**: Interactive charts
